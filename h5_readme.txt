HDF5 原始结构
层级：subject_X → exercise (AS/CB/EF/ER/OR) → speed (F/N/S/VF/90/180/M)
数据集：每个叶子节点是一个 (T, D) 的 object 数组。
D（列数）有 108、111、112 三种维度。
112 维：包含 时间戳，处理时被去掉（data = data[:, :-1] → 变 111 维）。
108/111 维：是有效传感器+轨迹数据。
NPZ 输出结构
X: (N, 39, 50)
39 = 统一后的传感器维度（108维补3个零通道 → 36+3=39；111维直接取前39）。
50 = 滑动窗口长度（WINDOW_LEN=50）。
Y_cls: (N,) → 动作类别标签（AS=0, CB=1...）。
Y_traj: (N, 72) → 轨迹真值（取原始数据最后72维，对应9关节×8未来步）。
H5 → NPZ 转换核心逻辑
遍历 HDF5 所有 subject/exercise/speed 路径。
统一维度：
112维 → 去掉最后一列（时间戳）→ 111维。
108维 → 补3个零通道 → 111维。
最终所有数据变为 111维（39传感器 + 72轨迹）。
滑动窗口切片：
以 WINDOW_LEN=50、STRIDE=10 切分时序。
每个窗口的传感器部分（前39维）转置为 (39, 50) 作为 X。
窗口起始时刻的轨迹（后72维）作为 Y_traj。
保存为 ultra_train.npz。

1. 标签字母含义（HDF5路径）：
第一层 subject_X：受试者编号（1-13）。
第二层 exercise：运动类型，AS=上楼梯, CB=坐站平衡, EF=抬脚, ER=抬手够物, OR=跨越障碍。
第三层 speed/condition：动作变体，如 F=向前, N=正常, S=侧向, VF=极快, 90/180=转向角度, M=内侧。
2. NPZ中的标签处理：
Y_cls：将5种 exercise（AS/CB/EF/ER/OR）映射为整数标签 0~4，忽略 speed 子类。
Y_traj：取原始数据最后72维（9个关节×8个未来时间步的轨迹真值），未做平均。
3. 滑动窗口切分（WINDOW_LEN=50, STRIDE=10）：
目的：将长时序信号切分为固定长度片段用于训练。
操作：对每个 (T, 111) 的连续数据（T为总长度），从起始位置开始：
取 50个连续时间步 作为一个窗口（即 data[i:i+50, :]）。
窗口每次右移10步（STRIDE=10），生成下一个样本。
结果：
输入 X：每个窗口的前39维（传感器）转置为 (39, 50)（通道×时间）。
输出 Y_traj：窗口起始时刻（第 i 步）对应的72维轨迹真值。
非平均：直接截取原始数据片段，未进行任何平均或聚合。
